# 2026-06-28 T4x2 Fix

## Problem

The first PyTorch MNIST GPU baseline failed because the Kaggle CLI was called with generic:

```powershell
--accelerator gpu
```

Kaggle allocated:

```text
Tesla P100-PCIE-16GB
```

The default Kaggle PyTorch build could see CUDA, but failed at execution time because P100 compute capability `sm_60` is unsupported by the installed PyTorch build.

## Investigation

Inspected the installed Kaggle SDK and found documented machine-shape values:

```text
NvidiaTeslaT4
NvidiaTeslaP100
```

The Kaggle API request uses `machine_shape`. CLI `--accelerator` overrides metadata.

## Fix

Updated GPU metadata to request T4 explicitly:

```json
{
  "enable_gpu": "false",
  "machine_shape": "NvidiaTeslaT4"
}
```

Then pushed kernels without `--accelerator gpu`.

## Rule Going Forward

For Kaggle GPU experiments, use:

```json
"machine_shape": "NvidiaTeslaT4"
```

Do not use generic:

```powershell
--accelerator gpu
```

unless the task explicitly wants any available GPU and accepts P100 risk.
